# Design × Spec — onde o design prevalece

Regra do projeto: **a UI segue o design estritamente**. Quando o design diverge da spec,
vale o design. Esta tabela é a referência para os testes (que consultam por texto/role).

| Tema                             | Spec                                                            | Design (vale este)                                                                                                                                                                                                                                                                                                                          |
| -------------------------------- | --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Tema escuro + toggle (§4.1, T13) | claro/escuro + toggle                                           | **Tema único (claro)**; tokens dark guardados e desligados em `tokens.css`                                                                                                                                                                                                                                                                  |
| Toast "Desfazer"                 | 5 s                                                             | **6 s**, pausa com hover/foco (`--toast-timeout`)                                                                                                                                                                                                                                                                                           |
| Toque (TouchSensor)              | delay ~200 ms                                                   | **250 ms**                                                                                                                                                                                                                                                                                                                                  |
| Aspas na microcopy               | "título"                                                        | **'título'** (ex.: `Excluir 'Configurar CI…'?`)                                                                                                                                                                                                                                                                                             |
| Confirmação de exclusão          | Excluir "{título}"? Essa ação pode ser desfeita…                | Título `Excluir '{título}'?` + texto "O card sai do quadro. Você pode desfazer logo em seguida."; botões **Cancelar** (foco inicial) / **Excluir card**; `role="alertdialog"`                                                                                                                                                               |
| Botão criar                      | "+ Adicionar card" em cada coluna, com a coluna pré-selecionada | **"Adicionar card"** (ícone +) no cabeçalho; no mobile, botão fixo no rodapé. Não há botão por coluna nem campo de etapa no modal: **o card novo sempre entra no topo de 01 A fazer**                                                                                                                                                       |
| Quadro vazio CTA                 | "Criar primeiro card"                                           | **"Adicionar card"** sob "Seu quadro está vazio." / "Comece criando o primeiro card."                                                                                                                                                                                                                                                       |
| Busca sem resultado              | Nenhum card encontrado para "termo".                            | `Nenhum card encontrado para '{termo}'` + "Confira a grafia ou busque por outra palavra." + **Limpar busca**                                                                                                                                                                                                                                |
| Busca sem resultado na coluna    | —                                                               | "Nenhum card desta etapa corresponde à busca"                                                                                                                                                                                                                                                                                               |
| Colunas                          | A fazer · Fazendo · Concluído                                   | Igual, com número: **01 A fazer**, **02 Fazendo**, **03 Concluído**                                                                                                                                                                                                                                                                         |
| Contador                         | "A fazer · 4" / "2 de 4"                                        | Badge `4` / `2 de 4`                                                                                                                                                                                                                                                                                                                        |
| Rótulo da coluna (section)       | —                                                               | `aria-label="01 A fazer, 4 cards"` (com busca: `2 de 4 cards`)                                                                                                                                                                                                                                                                              |
| Barra de fluxo                   | —                                                               | Nova: "6 de 14 concluídos", `role="img"`, `aria-label="5 a fazer, 3 fazendo, 6 concluídos"`; vazio: "Nenhum card ainda"                                                                                                                                                                                                                     |
| Menu do card                     | Editar / Mover para / Excluir                                   | Igual; botão `Abrir menu do card '{título}'`                                                                                                                                                                                                                                                                                                |
| Anúncios DnD                     | §5                                                              | `Card '{t}' pego. Posição 1 de 5 em 01 A fazer. Use as setas para mover, Espaço para soltar, Esc para cancelar.` · `Card '{t}' sobre 02 Fazendo, posição 2 de 4.` · `Card '{t}' solto em 02 Fazendo, posição 2 de 4.` · `Movimento cancelado. Card '{t}' voltou para 01 A fazer, posição 1.` · menu: `Card '{t}' movido para 03 Concluído.` |
| Contador de caracteres           | —                                                               | `0/120` e `0/1000` sob os campos                                                                                                                                                                                                                                                                                                            |
| Modal editar                     | Igual ao criar + Excluir                                        | + linha com a etapa atual (ex.: ● 02 Fazendo)                                                                                                                                                                                                                                                                                               |
| Busca no mobile                  | pode recolher                                                   | Recolhida em ícone `Buscar cards`; seletor de etapas 01 · 02 · 03 (`nav aria-label="Etapas do quadro"`)                                                                                                                                                                                                                                     |
| Live region do toast             | —                                                               | Anúncio: `Card excluído. Desfazer disponível por 6 segundos.` (região viva única, `role="status"`)                                                                                                                                                                                                                                          |
| Teclado no card                  | Enter abre edição; Espaço/Enter pegam o card                    | **Espaço** pega/solta, **Enter** abre a edição (ou solta, durante o arraste), Esc cancela                                                                                                                                                                                                                                                   |
